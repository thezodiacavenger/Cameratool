USB mode per brand
  • Nikon - USB: MTP/PTP. Reads serial + newest photo's shutter count.
  • Canon - default (no Wi-Fi active). Live shutter counter on EOS bodies that expose it, plus newest photo.
  • Sony - USB Connection: MTP (or PC Remote). Newest photo is decoded. Mass Storage makes it appear as a card instead.
  • Fujifilm - Connection Setting: USB tether / PC auto for the live TotalShotCount; USB card reader mode appears as a card.
  • OM System / Olympus - choose MTP or PC (tether) on the USB prompt; Storage appears as a card.
  • Panasonic / Leica - PC (Storage) appears as a card; PC (Tether)/PTP for serial.
  • Close Windows Photos / Lightroom import / EOS Utility first - only one program can talk to a camera.

Intake procedure (recommended SOP)

  1. Record the serial from the body label / under the mount before anything else.
  2. Insert the store's own card, format it in the camera, and take 2 frames (mechanical shutter) a few seconds apart.
  3. Drop both files into Camera Check. Never accept files emailed or supplied by the seller - counters inside files can be edited.
  4. Confirm the serial match is green. A mismatch means the files or the body are not what they claim.
  5. For brands without file counters (OM System, Panasonic, Leica, Hasselblad, Fujifilm, most Canon DSLRs) follow the Brand guide, photograph the counter screen and attach it.
  6. Cinema cameras: photograph the system-info / hours-meter screen, enter runtime & sensor hours, attach the camera log if exported.
  7. Complete the functional checklist, then save. Print or save the report as PDF to the purchase file.
