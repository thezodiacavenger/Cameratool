USB mode per brand
  • Nikon - MTP/PTP. Reads serial + newest photo's shutter count.
  • Canon - default mode. Live counter on EOS bodies that expose it, plus newest photo.
  • Sony - USB Connection: MTP or PC Remote. Mass Storage appears as a card instead.
  • Fujifilm - USB tether / PC auto for the live TotalShotCount.
  • OM System - MTP or tether on the USB prompt.
  • Panasonic / Leica - PTP/tether for serial; PC (Storage) appears as a card.
  • Close Windows Photos, Lightroom import or EOS Utility first.

Recommended intake procedure

  1. Record the serial from the body label first.
  2. Use the store's own card; format it in the camera and shoot two frames.
  3. Read over USB or from the card reader - never accept seller-supplied files.
  4. Serial match must be green.
  5. For brands without file counters, follow the Brand guide and attach a photo of the counter screen.
  6. Complete the checks, save, and print or email the report card.
